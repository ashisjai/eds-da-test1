AEM Components → EDS Blocks Mapping

business.att.com | 68 Block Components

Overview

This document maps traditional AEM components to their Edge Delivery Services (EDS) block equivalents for the business.att.com migration. EDS uses a simplified content model with table-based authoring and client-side block decoration.

Key Differences

Architecture
Server-side rendering (HTL + Sling Models)
Client-side decoration (Vanilla JS)
Content Model
JCR nodes with dialog-defined properties
Table-based markdown/HTML
Styling
SCSS/LESS with clientlibs
Plain CSS with design tokens
Authoring
Touch UI dialogs
Universal Editor / Document Authoring
Variations
Style System + policies
Block variants (block-name-variant)
