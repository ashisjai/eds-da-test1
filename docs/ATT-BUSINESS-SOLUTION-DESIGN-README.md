How to generate the diagrams and Word document locally

Prerequisites:
- Docker (or Java + PlantUML + Graphviz)
- Pandoc
- Git

Quick local steps (using Docker + Pandoc):

1. Render PlantUML diagrams to PNG:

   mkdir -p diagrams/output
   docker run --rm -v "$(pwd)/diagrams:/workspace" plantuml/plantuml:latest -tpng /workspace/high-level-architecture.puml -o /workspace/output
   docker run --rm -v "$(pwd)/diagrams:/workspace" plantuml/plantuml:latest -tpng /workspace/content-authoring-flow.puml -o /workspace/output
   docker run --rm -v "$(pwd)/diagrams:/workspace" plantuml/plantuml:latest -tpng /workspace/ci-cd-flow.puml -o /workspace/output

2. Create generated Markdown (docs/ATT-BUSINESS-SOLUTION-DESIGN-with-diagrams.md):
   - Use the existing ATT-BUSINESS-SOLUTION-DESIGN.md as the base and append the Architecture Diagrams section, or use the provided docs/ATT-BUSINESS-SOLUTION-DESIGN-with-diagrams.md if present.

3. Convert to Word (.docx) with Pandoc:

   pandoc -s docs/ATT-BUSINESS-SOLUTION-DESIGN-with-diagrams.md -o ATT-BUSINESS-SOLUTION-DESIGN.docx --resource-path=.:diagrams/output

4. Commit the generated artifacts:

   git checkout deliverable/att-business-design
   git add ATT-BUSINESS-SOLUTION-DESIGN.docx docs/ATT-BUSINESS-SOLUTION-DESIGN-with-diagrams.md diagrams/output/*.png
   git commit -m "Add solution design docx with PlantUML diagrams (rendered PNGs + sources)"
   git push origin deliverable/att-business-design

Using the GitHub Actions workflow

- The workflow `.github/workflows/generate-docs.yml` (on this branch) will render the PlantUML diagrams and generate the DOCX automatically when pushed. It requires the workflow to have permission to push changes back to the branch; if branch protection prevents that, either run locally or adjust protection.

Notes & Troubleshooting

- If the workflow cannot push artifacts due to branch protection, create a PR and run the workflow manually (workflow_dispatch), then merge generated artifacts if needed.
- If images are too large inside Word, resize them using Word or adjust the width specified in the Markdown (e.g., `{ width=600px }`).
- To customize Word styles, provide a reference docx and pass it to pandoc with `--reference-doc=templates/att-reference.docx`.
