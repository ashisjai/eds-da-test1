1
Run EC/AEMcoder for Initial Migration
Execute automated migration tool to generate initial block structure, markdown content, and page scaffolding from source site.
Automation

Update Blocks, Functionality, CSS
Refine auto-generated blocks with brand compliance, accessibility fixes, responsive behavior, and interactive functionality.
Automation
2a
Extract Design System Tokens
Extract colors, typography, spacing from source site. Create CSS custom properties in styles.css for global consistency.
Design System
3
Create component-model.json
Define JCR package structure for AEM importer. Maps block content to AEM node structure for content storage.
Content Modeling
3a
Create component-definitions.json (UE)
Define Universal Editor field definitions. Creates authoring UI with field types, validation, and grouping for content authors.
Content Modeling
4
Review Pages, Re-author Assets in DAM
Validate migrated content accuracy. Upload images and documents to AEM DAM with proper metadata and folder structure.
Content Migration
4a
Create URL Redirect Mapping
Map old URLs to new EDS paths. Create 301 redirect rules to preserve SEO rankings and prevent broken links.
SEO & Routing
5
Move Servlets/APIs to Edge Workers
Migrate server-side logic to edge functions. Handle forms, pricing APIs, search, and personalization at the edge.
Edge Functions
5a
Setup Analytics/Tracking
Configure Adobe Launch tag management. Implement conversion tracking, event triggers, and third-party pixels.
Analytics
6
Migrate Custom Functionality to AEMaaCS
Port custom AEM components, services, and scheduled jobs to AEM as a Cloud Service architecture.
AEM Migration
7
Migrate Meta-schema, Taxonomy, Workflows, Users
Transfer content taxonomies, metadata schemas, approval workflows, and user/group permissions to AEMaaCS.
AEM Migration
8
Validate All Functionalities
Execute comprehensive QA testing. Verify all blocks, forms, APIs, accessibility (WCAG 2.1 AA), and performance targets.
Validation
